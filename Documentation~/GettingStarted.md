## Unity Project conversion guide for Unity PolySpatial XR

When porting existing Unity projects into PolySpatial XR, several considerations need to be taken into account. The biggest limitation is that some core Unity features aren't supported, and others provide a reduced feature set. In addition, input is different, and processing power and supported components will vary. Sometimes you will have to develop your own systems to support your unique project features and work around these limitations. You can find more information about porting your existing Unity project into PolySpatial XR in the [Porting existing unity projects into Unity PolySpatial XR](PortingUnityProjectsToPolySpatialXR.md) page.
